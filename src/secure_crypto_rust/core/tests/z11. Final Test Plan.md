# Test

Here’s a structured **final‑stage test plan** for our public API (`encrypt_stream_v2`, `decrypt_stream_v2`). The goal is to validate correctness, robustness, and telemetry behavior across all supported input/output abstractions and configurations.

---

## 🧪 Test Categories

### 1. **Round‑Trip Correctness**

- **Minimal plaintext**: Encrypt/decrypt a short string (`b"hello world"`) and assert equality.
- **Large plaintext**: Encrypt/decrypt multi‑MB input to stress chunking and parallelism.
- **Exact chunk boundaries**: Input size exactly equal to `HeaderV1.chunk_size` × N.
- **Empty input**: Expect `StreamError::SegmentWorker` or equivalent error.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_roundtrip.rs`

### 2. **InputSource Variants**

- **Memory**: `InputSource::Memory(Vec<u8>)`.
- **File**: Write plaintext to a temp file, use `InputSource::File`, assert decrypted output matches.
- **Reader**: Wrap a `Cursor<Vec<u8>>` in `InputSource::Reader`.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_input_variants.rs`

### 3. **OutputSink Variants**

- **Memory**: `OutputSink::Memory` with `ApiConfig.with_buf = Some(true)` → assert `snapshot.output` contains ciphertext.
- **File**: Write ciphertext to file, then decrypt from file.
- **Writer**: Use `Cursor<Vec<u8>>` wrapped in `OutputSink::Writer`.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_output_variants.rs`

### 4. **Header & Metadata Validation**

- **Header presence**: Assert ciphertext begins with valid `HeaderV1.magic` and length ≥ `HeaderV1::LEN`.
- **Flags**: Construct headers with different flags (`HAS_TOTAL_LEN`, `HAS_CRC32`, etc.) and assert they are preserved.
- **AAD domain mismatch**: Corrupt header field → expect `StreamError::Header`.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_header_meta.rs`

### 5. **Corruption Detection**

- **Bit‑flip in ciphertext**: Modify a byte inside a segment → expect `StreamError::SegmentWorker`.
- **Header corruption**: Flip a byte in header → expect `StreamError::Header`.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_corrupt_detection.rs`

### 6. **Parallelism Profiles**

- **Single‑threaded**: `HybridParallelismProfile::single_threaded()`.
- **Multi‑threaded**: `HybridParallelismProfile::new(4,4,8)` → assert decrypted output matches plaintext.
- **Extreme backpressure**: Very large input with small worker counts → ensure no deadlock.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_parallelism_profiles.rs`

### 7. **Telemetry & ApiConfig**

- **with_buf = Some(true)**: Assert `snapshot.output` contains ciphertext.
- **with_buf = None**: Assert `snapshot.output` is `None`.
- **collect_metrics = Some(true)**: (future‑proof) ensure snapshot still returns counters, even if unused.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_telemetry_config.rs`

### 8. **Compression & Cipher Variants**

- **Compression disabled**: `codec_ids::AUTO`.
- **Compression enabled**: `codec_ids::ZSTD` or `codec_ids::LZ4`.
- **Cipher variants**: `cipher_ids::AES256_GCM` vs `cipher_ids::CHACHA20_POLY1305`.
- **PRF variants**: `prf_ids::SHA256`, `prf_ids::BLAKE3K`.

#### 🧪 Test File: `secure_crypto_rust/core/tests/public_api/test_compression_cipher_variants.rs`

---

## ✅ Summary

Final stage tests should cover:

- **Correctness** (round‑trip, chunk boundaries, empty input).
- **All input/output abstractions**.
- **Header validation & corruption detection**.
- **Parallelism profiles & stress tests**.
- **Telemetry buffer extraction via `ApiConfig.with_buf`**.
- **Cipher/PRF/compression variants**.

This ensures our public API is validated across functional, robustness, and telemetry dimensions.

## 🧩 Notes

- **Profiles**:  
  - *Single‑Threaded*: `HybridParallelismProfile::single_threaded()`.  
  - *Multi‑Threaded*: e.g. `HybridParallelismProfile::new(4,4,8)`.  
  - *Extreme Backpressure*: large input with small worker counts (e.g. `HybridParallelismProfile::new(8,8,1)`).

- **ApiConfig**:  
  - `with_buf = None` → production default, no telemetry buffer.  
  - `with_buf = Some(true)` → test mode, capture ciphertext in `snapshot.output`.  

- **Corruption/Validation Tests**:  
  - Overlay corruption tests (bit‑flip in ciphertext, header mismatch) across **Memory → Memory** rows with both single‑threaded and multi‑threaded profiles.  
  - These don’t require file/reader variants, but we can extend if desired.

## ▶️ Running Tests

Since we have a **Cargo workspace**:

- To run **all tests in the workspace**:

  ```bash
  cargo test
  ```

- To run **all tests inside the `core` crate**:

  ```bash
  cargo test -p core
  ```

- To run **all tests inside the `public_api` folder**:

  ```bash
  cargo test -p core --test public_api
  ```

  Explanation:
  - `--test public_api` runs the integration test target named `public_api`.  
  - Cargo treats each file in `core/tests/public_api/` as part of the `public_api` integration test suite.

- To run a **specific test file**:

  ```bash
  cargo test -p core --test test_roundtrip
  ```

- To run a **specific test function**:

  ```bash
  cargo test -p core roundtrip_minimal_plaintext
  ```
